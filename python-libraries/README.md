# Video Games Table

This program holds onto video game data. 

<br>

1. Title
2. Developer (Company Who Created The Game)
3. Release Date

<br>

## Requirments

Consult the requirements.txt file. 
<br>
To install the requirments to run this file, run 'python -m pip install -r requirements.txt'
<br>

### Usage
Run the program with <br>
'python cli_data_entry.py'
