# Choice of Wiki: Monster Hunter Wiki
<p> I wanted to investigate which region in Monster Hunter Wilds was the most populated. 
Additionally, I wanted to see if there was a clear favorite in how much writing there was in a region of the game.
This web scraper collected 4 fields on information. </p>

1. Location: The six largest regions in the game.
2. Monster_List: The list of monsters that can appear in each region.
3. Word_Count: The total word count on each location page.
4. Unique_Links: THe total unique link count on each location page. 

<p> This data would be largely useful for investigating what areas may need more updates. 
If a region has a small monster_list or few words, it could be established that a region needs
more involvevment from developers. </p>

# Reflection
<p> With the data collected, we are able to investigate what regions of Monster Hunter Wilds are neglected.
If a region is populated with more monsters, more words/links on their wiki, then we can assume that 
a region is not neglected. That is not to say that regions with small populations are not extensively detailed or 
that work was not put into them. The data is a surface-level observation of how complex a region is in regards to 
its ecology and story. </p>
