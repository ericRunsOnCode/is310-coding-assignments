# In And Around Games : Maze

## Eric Campos

### Terminal Advice

1. "cd" - change directory forward
2. "cd ../" - change directory backward
3. "start" - can be used to open images from the command line.
4. "type" - can be used to open .txt files in the command line.

### Brief Instruction
Your goal is to find the center of the maze! There will be clues to guide you through this maze. Most of these clues will be trivia related. Good luck!
